* Intro
This is a literate configuration for NixOS with HomeManager configs, and consists of Emacs (elisp) configs in tandem with particular category.
Although category does not matter, having certain similar one's together is useful.
** Concept
The concept I have used is to write several chunk of src/code blocks in some big pictorial category, and give a header name. Namely the main ones which are repeated several times;
  1. =nixos-core= - Goes for core nixos modules
  2. =hm-config= - Applies for Home modules/Configs (=dotfiles/.config=)
  3. =orgmacs= - To babel for Emacs.
The idea was obtained from https://github.com/rasendubi/dotfiles, credits to him for creating elisp function for babeling repeating header names into a code block, with =noweb= support.

+*Q*: Why not tangle src blocks?
*→* Its a bit redundant to tangle each block, and also I found that org babel with =noweb= is pretty quicker than tangling 100++ +src blocks.+
*Edit:* I changed back to using tangle on each block. Since headings can be =COMMENT= out, also I did not understand using el-patch and just wanted to simplify.

Learning is the key here, its easy for me (maybe you?) to forget, and I don't want to visit each wiki page for each tool for what it does, or why did I write them.
It is as simple if I just record what it does, with proper link to rich resource, and done. It would be snappy for me to remember and understand whatever I wrote after long time.

*Update*
Down the line as of [2024-11-12 Tue], I think I'm moving towards more minimalism. I'm purging out most of the config lines, and staying as much vanilla or how tools were designed to use by the authors.
Inspired by [[https://arne.me/blog/we-need-more-zero-config-tools][Arne's zero config tool]]

It makes sense to just appreciate the developers intention and expected usage, rather than beating around the bush. Imo most of the tools come with sane defaults that we need to learn and take.

Also its crucial to only add configuration that is explicitly required, rather than jumping ships on trends.

Emacs configuration is crafted slowly by learning from all users in community. Especially planetemacs blog posts, minad packages and oantolin's package and config.

          internalInterfaces = ["ve-+"];

  // ============================================================================
  // UTILITIES

  function orderless_match(haystack: string, needle: string): boolean {
      if (!needle.trim()) return true;
      const hay = haystack.toLowerCase();
      const words = needle.toLowerCase().trim().split(/\s+/);
      return words.every(word => hay.includes(word));
  }

  // ============================================================================
  // TAB MANAGEMENT
  // ============================================================================

  async function show_tab_picker(action: 'close' | 'discard', filter_fn?: (tab: browser.tabs.Tab) => boolean) {
      const tabs = await browser.tabs.query({ currentWindow: true });
      const filtered = filter_fn ? tabs.filter(filter_fn) : tabs;
      const titles = { close: 'Kill Tab', discard: 'Discard Tab' };

      glide.commandline.show({
          title: `${titles[action]} (${filtered.length})`,
          options: filtered.map((tab) => ({
              label: tab.title || tab.url || "Untitled",
              description: tab.url,
              matches({ input }) {
                  return orderless_match(`${tab.title} ${tab.url}`, input);
              },
              async execute() {
                  if (tab.id === undefined) return;
                  if (action === 'close') {
                      await browser.tabs.remove(tab.id);
                  } else {
                      const current_tab = await glide.tabs.active();
                      if (current_tab.id === tab.id) {
                          const all_tabs = await browser.tabs.query({ currentWindow: true });
                          const idx = all_tabs.findIndex(t => t.id === current_tab.id);
                          const next = all_tabs[idx + 1] || all_tabs[idx - 1];
                          if (next?.id) await browser.tabs.update(next.id, { active: true });
                      }
                      await browser.tabs.discard(tab.id);
                  }
              },
          })),
      });
  }

  // HISTORY NAVIGATION

  async function show_history_picker(current_site_only: boolean = false) {
      const max_results = current_site_only ? 500 : 1000;
      const all_history = await browser.history.search({ text: "", startTime: 0, maxResults: max_results });

      let filtered = all_history;
      let title = `History (${all_history.length})`;

      if (!current_site_only) {
          const seen = new Set<string>();
          filtered = filtered.filter(item => {
              const canonical = item.url.split("#")[0];
              if (seen.has(canonical)) return false;
              seen.add(canonical);
              return true;
          });
      }

      if (current_site_only) {
          const active_tab = await glide.tabs.active();
          if (!active_tab?.url) return;

              try { return new URL(active_tab.url).origin; }

  // LINK PICKER - Choose links on page
  // ============================================================================

  async function show_link_picker(open_in_new_tab: boolean = false, yank: boolean = false) {
      const current_tab = await get_current_tab();
      if (!current_tab.id) return;

      let links: Array<{ text: string; href: string; context: string }>;

      try {
          links = await glide.content.execute(() => {
              const seen = new Set<string>();
              const results: Array<{ text: string; href: string; context: string }> = [];
              const MAX = 1000;

              const clean = (s: string) => s.trim().replace(/\s+/g, ' ');
              const truncate = (s: string, max: number) => s.length > max ? s.slice(0, max) + '…' : s;

              const BLOCK_TAGS = new Set(['LI', 'TR', 'TD', 'TH', 'ARTICLE', 'SECTION', 'MAIN', 'HEADER', 'FOOTER', 'BODY']);

              const get_context = (el: Element): string => {
                  const link_text = clean(el.textContent || '');
                  let node: Element | null = el.parentElement;
                  for (let i = 0; i < 5 && node; i++) {
                      const ctx = clean(node.textContent || '').replace(link_text, '').trim();
                      if (ctx.length > 2) return truncate(ctx, 60);
                      if (BLOCK_TAGS.has(node.tagName)) break;
                      node = node.parentElement;
                  }
                  return '';
              };

              for (const el of document.querySelectorAll('a[href]')) {
                  if (results.length >= MAX) break;
                  const a = el as HTMLAnchorElement;
                  if (!a.href || seen.has(a.href)) continue;
                  seen.add(a.href);
                  const text = truncate(clean(
                      a.textContent ||
                          a.getAttribute('aria-label') ||
                          a.getAttribute('title') ||
                          ''
                  ), 100);
                  if (text.length < 2) continue;
                  results.push({ text, href: a.href, context: get_context(a) });
              }

              const url_re = /https?:\/\/[^\s<>"'{}|\\^`[\]]+/g;
              const skip_tags = new Set(['SCRIPT', 'STYLE', 'NOSCRIPT']);
              const walker = document.createTreeWalker(document.body, NodeFilter.SHOW_TEXT, {
                  acceptNode(node) {
                      const parent = node.parentElement;
                      return parent && skip_tags.has(parent.tagName)
                          ? NodeFilter.FILTER_REJECT
                          : NodeFilter.FILTER_ACCEPT;
                  }
              });
              let scanned = 0;
              let node: Node | null;
              while ((node = walker.nextNode()) && scanned < 500 && results.length < MAX) {
                  scanned++;
                  for (const match of (node.textContent || '').matchAll(url_re)) {
                      const url = match[0].replace(/[.,;:!?)\]>]+$/, '');
                      if (url && !seen.has(url)) {
                          seen.add(url);
                          results.push({ text: url, href: url, context: '' });
                      }
                  }
              }

              return results;
          }, { tab_id: current_tab.id });
      } catch (error) {
          console.error('Link picker error:', error);
          return;
      }

      const title = yank ? 'Yank Link' : open_in_new_tab ? 'Open Link in New Tab' : 'Open Link';
      glide.commandline.show({
          title: `${title} (${links.length})`,
          options: links.map((link) => ({
              label: link.text,
              description: link.context ? `${link.context}  •  ${link.href}` : link.href,
              matches({ input }) {
                  return orderless_match(`${link.text} ${link.context} ${link.href}`, input);
              },
              async execute() {
                  if (yank) {
                      await glide.content.execute(
                          (href: string) => navigator.clipboard.writeText(href),
                          { tab_id: current_tab.id, args: [link.href] }
                      );
                  } else if (open_in_new_tab) {
                      await browser.tabs.create({ url: link.href });
                  } else {
                      await browser.tabs.update(current_tab.id, { url: link.href });
                  }
              },
          })),
      });
  }

  // ============================================================================
  // PAGE NAVIGATOR - Navigate page structure

  async function show_page_navigator() {
      const current_tab = await get_current_tab();
      if (!current_tab.id) return;

      let items: Array<{ type: string; text: string; detail?: string; xpath: string }>;

      try {
          items = await glide.content.execute(() => {
              const results: Array<{ type: string; text: string; detail?: string; xpath: string }> = [];
              const MAX = 500;

              const get_xpath = (element: Element): string => {
                  if (element.id) return `//*[@id="${element.id}"]`;
                  let path = '';
                  let el: Element | null = element;
                  for (; el && el.nodeType === 1; el = el.parentElement) {
                      let index = 0;
                      for (let sibling = el.previousSibling; sibling; sibling = sibling.previousSibling) {
                          if (sibling.nodeType === Node.ELEMENT_NODE && (sibling as Element).tagName === el.tagName) index++;
                      }
                      path = '/' + el.tagName.toLowerCase() + '[' + (index + 1) + ']' + path;
                  }
                  return path;
              };

              const clean = (text: string, max: number = 80): string => {
                  const t = text.trim().replace(/\s+/g, ' ');
                  return t.length > max ? t.substring(0, max) + '...' : t;
              };

              document.querySelectorAll('h1, h2, h3, h4, h5, h6').forEach(el => {
                  if (results.length >= MAX) return;
                  const level = el.tagName[1];
                  results.push({
                      type: 'heading',
                      text: `${'  '.repeat(Number(level) - 1)}${el.tagName}: ${clean(el.textContent || '')}`,
                      detail: el.id ? `#${el.id}` : '',
                      xpath: get_xpath(el)
                  });
              });

              document.querySelectorAll('main, nav, header, footer, article, section').forEach(el => {
                  if (results.length >= MAX) return;
                  results.push({
                      type: 'landmark',
                      text: `<${el.tagName.toLowerCase()}> ${clean(el.textContent || '', 50)}`,
                      detail: el.id ? `#${el.id}` : '',
                      xpath: get_xpath(el)
                  });
              });

              document.querySelectorAll('p, li, dt, dd, figcaption, blockquote').forEach(el => {
                  if (results.length >= MAX) return;
                  const text = clean(el.textContent || '', 120);
                  if (text.length > 5) {
                      results.push({ type: 'text', text, detail: '', xpath: get_xpath(el) });
                  }
              });

              return results;
          }, { tab_id: current_tab.id });
      } catch (error) {
          console.error('Page navigator error:', error);
          return;
      }

      if (items.length === 0) {
          await show_link_picker(false);
          return;
      }

      glide.commandline.show({
          title: `Navigate Page (${items.length})`,
          options: items.map((item) => ({
              label: item.text,
              description: item.detail,
              matches({ input }) {
                  return orderless_match(item.text, input);
              },
              async execute() {
                  await glide.content.execute((xpath: string) => {
                      const el = document.evaluate(xpath, document, null, XPathResult.FIRST_ORDERED_NODE_TYPE, null).singleNodeValue as HTMLElement;
                      if (el) {
                          el.scrollIntoView({ behavior: 'smooth', block: 'center' });
                          const orig = el.style.outline;
                          el.style.outline = '3px solid orange';
                          setTimeout(() => { el.style.outline = orig; }, 2000);
                      }
                  }, { tab_id: current_tab.id, args: [item.xpath] });
              },
          })),
      });
  }

  // ============================================================================
  // URL RULES - Redirect & Block
  // ============================================================================

  interface URLRule {
      domain: string;
      action: 'redirect' | 'block';
      to?: string;
      paths?: string[];
  }

  const URL_RULES: URLRule[] = [
      { domain: 'reddit.com', action: 'redirect', to: 'https://redlib.catsarch.com$1' },
      { domain: 'twitter.com', action: 'redirect', to: 'https://nitter.net$1' },
      { domain: 'medium.com', action: 'redirect', to: 'https://scribe.rip$1' },
      // { domain: 'youtube.com', action: 'redirect', to: 'https://yewtu.be$1' },
      // { domain: 'youtube.com', action: 'block' },
      // { domain: 'youtube.com', action: 'block', paths: ['/shorts/'] },
  ];

  const _RULES_VER = String(Date.now());
  const _RULES_VER_KEY = 'GLIDE_URL_RULES_VER';

  function handle_url_rules(
      details: browser.webRequest.OnBeforeRequestDetailsType
  ): browser.webRequest.BlockingResponse {
      if (glide.env.get(_RULES_VER_KEY) !== _RULES_VER) return {};

      const url = details.url;
      try {
          const url_obj = new URL(url);
          const hostname = url_obj.hostname.replace(/^www\./, '');

          for (const rule of URL_RULES) {
              const domain = rule.domain.replace(/^www\./, '');
              if (hostname !== domain && !hostname.endsWith('.' + domain)) continue;

              if (rule.paths) {
                  if (!rule.paths.some(p => url_obj.pathname.includes(p))) continue;
              }

              if (rule.action === 'block') return { redirectUrl: 'about:blank' };

              if (rule.action === 'redirect' && rule.to) {
                  try {
                      const target_host = new URL(rule.to.replace('$1', '/')).hostname.replace(/^www\./, '');
                      if (hostname === target_host || hostname.endsWith('.' + target_host)) continue;
                  } catch {}
                  const path = url_obj.pathname + url_obj.search + url_obj.hash;
                  return { redirectUrl: rule.to.replace('$1', path) };
              }
          }
      } catch (e) {
          console.error('URL rule error:', e);
      }
      return {};
  }

  function setup_redirects() {
      glide.env.set(_RULES_VER_KEY, _RULES_VER);
      browser.webRequest.onBeforeRequest.removeListener(handle_url_rules);
      browser.webRequest.onBeforeRequest.addListener(
          handle_url_rules,
          { urls: ['<all_urls>'], types: ['main_frame'] },
          ['blocking']
      );
  }

    // @name Redirect Script
    // @namespace https://example.com

    // @description Redirects URLs by replacing values from config
    // @match *://*/*
    // @run-at document-start
    // @grant none
    // ==/UserScript==

    (function() {
        'use strict';

        var currentUrl = window.location.href;
        var config = {
    //      'from': 'to',
            // '^(?:https?://)(?:www.)?youtube.com/shorts/': 'https://yewtu.be/watch?v=',
            // '^(?:https?://)(?:www.)?youtube.com': 'https://yewtu.be',
            '^(?:https?://)(?:www.)?reddit.com': 'http://test.local:9999',
            '^(?:https?://)(?:www.)?old.reddit.com': 'http://test.local:9999',
        };
        
        for (var oldValue in config) {
            var newValue = config[oldValue];
            var regex = new RegExp(oldValue, 'g');
            currentUrl = currentUrl.replace(regex, newValue);
        }
        
        if (currentUrl !== window.location.href) {
            window.location.href = currentUrl;
        }
    })();

  (defun d/keyboard-quit-dwim ()
    "Do-What-I-Mean behaviour for a general `keyboard-quit'.

  The generic `keyboard-quit' does not do the expected thing when
  the minibuffer is open.  Whereas we want it to close the
  minibuffer, even without explicitly focusing it.

  The DWIM behaviour of this command is as follows:

  - When the region is active, disable it.
  - When a minibuffer is open, but not focused, close the minibuffer.
  - When the Completions buffer is selected, close it.
  - In every other case use the regular `keyboard-quit'."
    (interactive)
    (cond
     ((region-active-p)
      (keyboard-quit))
     ((derived-mode-p 'completion-list-mode)
      (delete-completion-window))
     ((> (minibuffer-depth) 0)
      (abort-recursive-edit))
     (t
      (keyboard-quit))))

*** Org Mode
The art of note taking is for efficient retrieval, not an system like zettelkasten or roam research.

Leveraging the capabilities of org mode puts upon better use for organizing and integrating tools and functions.
Many of Karl voit's post elaborate and give ideas on this matter.

My workflow is to adapt the timestamp as =org-id= such that each heading becomes unique to refer.
Then tag all heading with appropriate keywords for retrieval.

Tags are not just defined in general terms, but in category. With a prefix, =t@context= : where T stands for task, and context can be work, bill, repair.

This helps in maintain single big org file in =datetree= journal, and hence no more fear of missing out information or files. Everything at one spot.

Gist: *Capture/narrow -> Tags + ID + Link -> Note -> Export/Filter*

- the way to organize stuffs, and get things done!
- https://orgmode.org

A good explanation on task management can be found over this discussion.
https://list.orgmode.org/8734e756bn.fsf@gnu.org/T/#u

- My blog post on the same: https://idlip.in/posts/obtf-org-mode

- Command to Launch apps and easy to bind keys
  Parse desktop actions and show for completing read to run.

#+begin_src emacs-lisp
  ;;; Unified launcher with PATH executables + .desktop actions
  (declare-function ewm-list-xdg-apps "ewm-core")

  (defvar ewm-launcher-cache nil "Cache of (display-string . command) pairs.")

  (defun ewm-launcher--execute (cmd method)
    "Execute CMD using METHOD."
    (pcase method
      ('start-process      (start-process-shell-command cmd nil cmd))
      ('call-process       (call-process-shell-command cmd))
      ('async-shell-buffer (async-shell-command cmd))
      ('output-echo        (message "%s" (string-trim (shell-command-to-string cmd))))
      ('output-buffer      (with-current-buffer (get-buffer-create "*ewm-output*")
                             (erase-buffer)
                             (insert (shell-command-to-string cmd))
                             (goto-char (point-min))
                             (display-buffer (current-buffer))))
      ('insert-output      (insert (shell-command-to-string cmd)))
      ('compile-buffer     (compile cmd))))

  (defun ewm-launcher--desktop-actions (file)
    "Return Desktop Action entries from FILE as (\"App: Action\" . cmd) pairs."
    (when (file-readable-p file)
      (with-temp-buffer
        (insert-file-contents file)
        (let (app-name actions)
          (when (re-search-forward "^\\[Desktop Entry\\]" nil t)
            (let ((end (or (save-excursion (re-search-forward "^\\[" nil t)) (point-max))))
              (when (re-search-forward "^Name=\\(.+\\)" end t)
                (setq app-name (string-trim (match-string 1))))))
          (goto-char (point-min))
          (while (re-search-forward "^\\[Desktop Action .+?\\]" nil t)
            (let ((start (point))
                  (end   (or (save-excursion (re-search-forward "^\\[" nil t)) (point-max)))
                  action-name action-exec)
              (when (re-search-forward "^Name=\\(.+\\)" end t)
                (setq action-name (string-trim (match-string 1))))
              (goto-char start)
              (when (re-search-forward "^Exec=\\(.+\\)" end t)
                (setq action-exec (string-trim
                                   (replace-regexp-in-string " %[uUfFdDnNickvm].*$" "" (match-string 1)))))
              (when (and app-name action-name action-exec)
                (push (cons (format "%s: %s" app-name action-name) action-exec) actions))))
          (nreverse actions)))))

  (defun ewm-launcher--build-cache ()
    "Build cache of PATH executables + XDG desktop apps + desktop actions."
    (require 'xdg)
    (let (entries seen)
      ;; PATH executables
      (dolist (dir (seq-filter #'file-directory-p exec-path))
        (dolist (file (directory-files dir nil "^[^.]"))
          (let ((full (expand-file-name file dir)))
            (when (and (file-regular-p full) (file-executable-p full)
                       (>= (length file) 3) (not (member file seen)))
              (push file seen)
              (push (cons file file) entries)))))
      ;; XDG desktop apps via ewm
      (dolist (app (ewm-list-xdg-apps))
        (let ((label (car app))
              (cmd (string-trim (replace-regexp-in-string " %[uUfFdDnNickvm]" "" (cdr app)))))
          (unless (member label seen)
            (push label seen)
            (push (cons label cmd) entries))))
      ;; Desktop Actions from .desktop files
      (dolist (dir (mapcar (lambda (d) (expand-file-name "applications" d)) (xdg-data-dirs)))
        (dolist (file (when (file-directory-p dir) (directory-files dir t "\\.desktop$"))) 
          (dolist (action (ewm-launcher--desktop-actions file))
            (unless (member (car action) seen)
              (push (car action) seen)
              (push action entries)))))
      (nreverse entries)))

  (defun ewm-launch (arg &optional cmd)
    "Launch executable or desktop app. Prefix selects execution method:
    C-u=prompt  1=output-buffer  2=echo  3=async  4=compile  5=sync  6=insert"
    (interactive "P")
    (if cmd
        (ewm-launcher--execute cmd 'start-process)
      (unless ewm-launcher-cache
        (setq ewm-launcher-cache (ewm-launcher--build-cache)))
      (let* ((input (completing-read "Run: " ewm-launcher-cache nil nil))
             (cmd   (or (cdr (assoc input ewm-launcher-cache)) input))
             (method (cond
                      ((equal arg '(4)) (intern (completing-read "Execute as: "
                                                 '("start-process" "call-process"
                                                   "async-shell-buffer" "output-echo"
                                                   "output-buffer" "compile-buffer"
                                                   "insert-output") nil t)))
                      ((equal arg 1) 'output-buffer)
                      ((equal arg 2) 'output-echo)
                      ((equal arg 3) 'async-shell-buffer)
                      ((equal arg 4) 'compile-buffer)
                      ((equal arg 5) 'call-process)
                      ((equal arg 6) 'insert-output)
                      (t             'start-process))))
        (ewm-launcher--execute cmd method))))

  (defun d/completing-read-file (file-or-files &optional return-re prompt)
    "Present lines of FILE-OR-FILES as completing-read candidates.
  FILE-OR-FILES may be a string or a list of strings; lines from all
  files are concatenated.  Return the selected line, or when
  RETURN-RE is given, return the first capturing group of that
  regexp applied to the selection (falls back to the whole match if
  no capturing group).  PROMPT defaults to \"Select: \"."
    (let* ((files (if (listp file-or-files) file-or-files (list file-or-files)))
           (lines (mapcan (lambda (f)
                            (with-temp-buffer
                              (insert-file-contents (expand-file-name f))
                              (split-string (buffer-string) "\n" t)))
                          files))
           (selected (completing-read (or prompt "Select: ") lines nil nil)))
      (if return-re
          (when (string-match return-re selected)
            (or (match-string 1 selected) (match-string 0 selected)))
        selected)))
